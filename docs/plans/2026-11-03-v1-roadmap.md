# Tachylite v1 roadmap

**Spec:** `docs/superpowers/specs/2026-11-03-tachylite-design.md`, summarised as user stories in #14. Read it first; this file only orders the work.

v1 ships in ten slices. Each slice is one GitHub issue under the `v1` milestone, one branch and one or more PRs. Each one ends with working software and its budgets green. A slice gets its detailed plan in `docs/plans/` when it starts, so it can build on what the slices before it learned. Only slice 1 has a detailed plan so far.

The order follows one rule: prove the riskiest claim first. That claim is that a save reaches an open page in about 100 ms, so slice 2 builds that path end to end, and breadth comes after it.

## Output layout

Slice 1 fixes this. Later slices add to it but never move it.

- `out/.tachylite-output`: a marker file. Tachylite clears or writes only a directory that is empty or carries this marker.
- `out/pages/<vault path without .md>.html`: note pages.
- `out/files/<vault path>`: html pages and assets, byte for byte.

The server percent-decodes the URL path to `P`. It serves `pages/P.html` if that exists, else `files/P`. So `/maps/route` serves the note `maps/route.md`, and `/maps/route.html` serves the html page `maps/route.html`. They never share a file. One clash remains: the note `a.html.md` and the html page `a.html` both want `/a.html`. #17 tracks it.

A path with an empty, `.` or `..` segment after decoding gets a 404. So does a path ending in `/`; folder indexes have their own URLs.

Generated pages live in `out/pages/.tachylite/`, and other generated files in `out/files/.tachylite/`. No vault path starts with `.`, so the same routing rule serves them, and no vault file can take their place. Three URLs sit outside the rule, and the server answers them before the file lookup:

- `/` serves the home page from `out/pages/.tachylite/home.html`.
- `/.tachylite/folders/<folder>` serves that folder's index from `out/pages/.tachylite/folders/<folder>/.index.html`. A dot name inside the folder's own path is a name no folder can have, so folder `a` and folder `a.html/b` never need the same path.
- `/.tachylite/events?page=<encoded pathname>&v=<version>` is the SSE endpoint. A page subscribes to its own pathname.

Tachylite writes each output file as a hidden `.tmp` beside it, then renames it into place. One short name fits beside a name of any length, and one name per folder is enough, because a writer writes one file at a time. A note whose page name, `<name>.html`, would pass the filesystem's 255-byte limit is skipped and logged, like a URL clash. A reader never sees half a file, and no URL reaches a temp file, because the server 404s any segment that starts with `.`.
